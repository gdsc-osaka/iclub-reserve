# ADR-006: 団体の連絡先フィールドを廃止しメンバーのメールアドレスで代替する

- **ステータス**: Accepted
- **決定日**: 2026-03-18
- **決定者**: GDG on Campus Osaka 開発チーム
- **関連 RDRA**: INFO-003, INFO-005, INFO-006, REQ-017, REQ-020, SCR-007

---

## コンテキスト

事務局が団体に連絡を取る手段が必要。当初は INFO-003（団体）に `contact_email` フィールドを設けることを検討したが、以下の特性を踏まえて廃止を決定した。

- システムの利用者は osaka-u.ac.jp ドメインの学内ユーザーに限定されている（COND-004）
- 団体のオーナーは必ず学内メールアドレスを持ち、メンバーシップ（INFO-005）経由で参照できる
- 通知メールはすでにオーナー全員に送信される設計になっている（EVT-001〜007 等）

## 選択肢

| 案 | 方式 | 採否 |
|----|------|------|
| A（採用） | 連絡先フィールドを持たず、INFO-005（メンバーシップ）経由でオーナーのメールアドレスを連絡先とする | ✅ |
| B | INFO-003 に `contact_email` フィールドを持つ | ❌ |
| C | B に加えてメンバーメールも参照できるようにする | ❌ |

### 案B・C を却下した理由

- 団体への連絡先としてオーナーのメールアドレスで十分であり、独立したフィールドを維持する必要がない
- `contact_email` を別途管理すると「メンバーが変わったのに連絡先が古いまま」という更新漏れのリスクが生まれる
- メンバーシップ経由のオーナーメールを使うことで、osaka-u.ac.jp ドメインの学内メールアドレスであることが自動的に保証される

## 決定

**INFO-003（団体）に連絡先フィールドを持たず、INFO-005（メンバーシップ）経由でオーナーのメールアドレスを連絡先として扱う。**

- 団体管理画面（SCR-007）のメンバー一覧にメールアドレスを表示し、オーナー・事務局が参照できるようにする
- 通知イベント（EVT-001〜007 および事務局送信時の EVT-008）はオーナー全員に送信するため、連絡先フィールドを別途参照する必要はない

## 影響・トレードオフ

| 項目 | 内容 |
|------|------|
| 連絡先の鮮度 | オーナーが変わるとメンバーシップが更新されるため、連絡先が常に最新の状態に保たれる |
| 学内メール保証 | COND-004 により連絡先は必ず osaka-u.ac.jp ドメインのメールアドレスになる |
| SCR-007 の閲覧制限 | メンバー一覧のメールアドレスはオーナーと事務局のみ閲覧可能とし、一般メンバーには非表示にする |

## 将来の検討事項

現在は osaka-u.ac.jp ドメインのみを許可しているが、将来的に Gmail 等の個人アドレスでの利用要望が生じた場合は、INFO-006（ユーザー）に複数メールアドレスを持てるよう拡張するか、認証メールアドレスとは別に通知用メールアドレスをユーザー個人単位で設定できる仕組みを検討する。ただしこの対応は SSO 移行（ADR-001）の方針とも合わせて判断する。
