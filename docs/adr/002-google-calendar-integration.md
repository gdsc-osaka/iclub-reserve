# ADR-002: Google Calendar 連携方式 — Service Account によるシステム管理

- **ステータス**: Accepted
- **決定日**: 2026-03-18
- **決定者**: GDG on Campus Osaka 開発チーム
- **関連 RDRA**: BIZ-005, REQ-026, REQ-027, REQ-028, REQ-030, INFO-002（google_calendar_id）

---

## コンテキスト

- 承認済み予約の状況を外部に公開する手段として Google Calendar を使う（GOAL-004）
- 施設ごとに個別のカレンダーを作成し、承認・キャンセル・変更を自動反映する（REQ-026〜028）
- 公開情報は団体名・施設名・日時のみ（使用人数・備考は非公開）
- インフラは Google Cloud に統一する方針（ADR-001）
- 現状は Google Calendar の iframe 埋め込みで予約状況を外部公開しているが、実質的に稼働していないため新規構築として設計する

## 選択肢

| 案 | 方式 | 採否 |
|----|------|------|
| **A（採用）** | Google Service Account でシステムがカレンダーを管理 | ✅ |
| B | 事務局ユーザーの Google アカウントで OAuth 認証してカレンダーを操作 | ❌ |
| C | Google Calendar を使わず独自の公開カレンダーページを実装 | ❌ |

### 案B を却下した理由

特定の事務局ユーザーのアカウントに依存するため、そのユーザーが退職・異動した際に Google Calendar 連携が切れるリスクがある。

### 案C を却下した理由

Google Calendar はユーザーが自分のカレンダーアプリに購読追加できる（iCal 形式）という汎用的な仕組みを持つ。独自実装ではこの利便性を再現できず、実装コストに見合わない。

## 決定

**Google Service Account を使い、システムが施設ごとの Google Calendar を所有・管理する。**

### セットアップ構成

```
GCP プロジェクト
  └─ Service Account（例: iclub-reserve@<project-id>.iam.gserviceaccount.com）
       └─ 秘密鍵（JSON）→ 本番: Secret Manager / ローカル開発: 環境変数（.env）

Google Calendar（施設ごとに1つ）
  └─ 所有者: Service Account
  └─ 公開設定: 一般公開（閲覧のみ）
  └─ カレンダーID → INFO-002.google_calendar_id に登録
```

### バックエンドの動作

1. 予約が承認されると（UC-006 / UC-008）、バックエンドが Service Account の秘密鍵で Google Calendar API を呼び出し、該当施設のカレンダーにイベントを登録する（EVT-009）
2. キャンセル・差し戻し時（UC-004 / UC-005 / UC-007 / UC-008）にイベントを削除する（EVT-010）
3. 事務局が承認済み予約の公開フィールド（施設名・日時）を直接変更した場合にイベントを更新する（EVT-011）

### 公開方式

カレンダーを一般公開（閲覧のみ）に設定することで、追加実装なしに以下の両方が利用できる。

| 公開方式 | 用途 |
|---------|------|
| iframe 埋め込み | 外部公開ページへの予約状況の埋め込み表示 |
| iCal 購読 URL | ログイン済みユーザーが自分のカレンダーアプリに追加（SCR-010 / REQ-030） |

## 影響・トレードオフ

| 項目 | 内容 |
|------|------|
| 秘密鍵の管理 | 本番環境では Secret Manager（Google Cloud）で管理する。環境変数への長期秘密鍵の設定はログや設定ファイル経由で漏洩するリスクがあるため、ローカル開発時のみ `.env` への設定を許容する。漏洩時は即座にローテーションする |
| カレンダー所有権 | カレンダーは Service Account が所有するため、GCP プロジェクトが失われると連携も失われる |
| INFO-002.google_calendar_id | 施設ごとのカレンダー ID を登録していない場合、Calendar 連携をスキップする（未設定施設はカレンダー未反映） |
| Google Calendar API 制限 | 無料枠内で運用できる見込みだが、大量の予約更新が発生する場合はクォータに注意する |
