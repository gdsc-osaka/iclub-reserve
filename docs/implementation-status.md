実装が進んでいるのは認証（BIZ-006）と団体管理（BIZ-003）および施設管理（BIZ-004）である。団体管理は当初 Better Auth の組織プラグインに乗せていたが、ADR-003 で撤去し、`group` / `group_member` / `group_invitation` の自前テーブルとユースケースに移した。招待は送信（UC-011）から承諾・辞退（UC-022）まで一通りつながっており、事務局による団体の有効化・無効化（UC-014）も実装した。予約（BIZ-001）は空き状況の確認（UC-001）、仮予約の申請（UC-002）、自団体・事務局の予約一覧表示および状態変更操作（SCR-003 フェーズ2: 取り消し・キャンセル・承認・却下）まで実装した。申請・状態変更の通知メール（EVT-001・002・003・005・006・007）は Transactional Outbox 経由で配送キューに積む仕組みまで実装済みである。施設管理（BIZ-004）は事務局による施設・設備の新規登録・編集・無効化/再有効化（UC-015・UC-016、SCR-009）および一覧確認（REQ-022〜REQ-025）を実装した。施設写真の保存先として Cloudflare R2（ADR-005）を導入し、認証付きリソースルート `/facility-photos/:photoName` による配信まで接続済みである。アカウント設定（SCR-021）は、氏名の変更（UC-029）、メールアドレス変更ダイアログ（SCR-017 / UC-023 / EVT-016）、パスキー管理（UC-021 / UC-030）、端末セッション管理（UC-031）およびサーバーフックでの各種検証（COND-004・017〜020）を実装した。予約承認（BIZ-002）やカレンダー連携（BIZ-005）の外部連携は未着手である。2026-09-23 に追加した操作履歴（BIZ-007）と事務局権限の付与・剥奪（REQ-041）も未着手である。同じく 2026-09-24 に、実装済みでよく使う動作なのに UC が無かったもの（予約一覧・予約詳細・所属団体の確認・ログアウト）を UC-032〜036 として追加した。このうち予約詳細（UC-034）は画面（SCR-005）を実装し、可視範囲に応じた詳細の表示と状態変更操作まで対応した。
